# SymboleoAC-Web IDE — logo package

Mark: "Sealed Sigma" — a folded-corner document carrying a capital Σ, with a padlock on its corner
(formal symbol · contract · access control).

## Files
- symboleoac-mark.svg / -dark.svg / -mono.svg — the mark alone (light backgrounds, dark backgrounds, single colour via currentColor)
- symboleoac-lockup.svg / -dark.svg — horizontal mark + wordmark (text converted to outlines; no font needed)
- symboleoac-lockup-stacked.svg / -dark.svg — mark above wordmark, for splash screens and README headers
- symboleoac-favicon.svg, favicon.ico, png/favicon-*.png — simplified, bolder version tuned for 16–48 px
- symboleoac-app-icon.svg, png/app-icon-*.png — white mark on a navy tile for PWA / manifest icons
- png/ — rasters of everything above

## Colours
- Ink (page, Σ, wordmark): #22304F
- Accent (lock, "AC"): #C8102E  · on dark backgrounds use #E0263F
- Dark background: #0F172E  · light background: #F6F5F1

## Type
Wordmark: Space Grotesk Bold (SIL Open Font License), letter-spacing −0.02em; "WEB IDE" in Space Grotesk Medium,
tracked +0.18em at 62% opacity. The SVGs carry the text as outlines, so nothing needs to be installed.

## Use
Keep clear space around the mark of at least the lock's height. Below 24 px use the favicon version.
Do not recolour the lock and the page the same colour except in the mono version.
